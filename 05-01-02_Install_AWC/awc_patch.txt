
# This patch must be applied to gain access to the Data Services tiles. 
# There is a Jira ticket seeking correction.

Check the current value :
-------------------
kubectl get secret awc-taikun-secrets -n awc-core \
  -o jsonpath='{.data.MARKETPLACE_REGISTRIES}' | base64 -d; echo

Update the value :
-------------------
kubectl patch secret awc-taikun-secrets -n awc-core -p '{"stringData": {"MARKETPLACE_REGISTRIES": "docker-private.infra.cloudera.com/cloudera/awc-marketplace/v2/int", "MARKETPLACE_SYNC_INTERVAL": "60"}}'

Restart the Deployment:
----------------------
kubectl rollout restart deployment/awc-console -n awc-core 2>&1 && kubectl rollout status deployment/awc-console -n awc-core 2>&1
